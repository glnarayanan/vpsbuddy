# Agent Notes

This repository contains the `vpsbuddy` Bash CLI for securely bootstrapping
fresh VPS hosts. Run the guided CLI on the VPS after the operator has logged in.

Keep this file lean. Load detailed docs in `documentation/` when changing
behavior:

- `documentation/README.md` for operator notes
- `documentation/security-model.md` for the phased hardening model
- `documentation/compatibility-matrix.md` for supported targets
- `documentation/release-process.md` for smoke-test guidance
- `documentation/provider-firewall-checklist.md` for provider firewall expectations
- `documentation/testing.md` for local checks
- `documentation/references.md` for upstream install/auth references
