## Vercel Agent Skills installer

Checked against the repository's `main` branch on 2026-07-31. The official
command is `npx skills add <source>`. The source sets a Node.js engine floor and
imports `@clack/prompts` and `picocolors`, so this is not a dependency-free Bash
implementation.

The useful interaction pattern is:

1. Select skills. One skill is selected without a prompt. Several skills use a
   required multi-select with short descriptions.
2. Detect agents. One detected agent is selected without a prompt. Several
   detected agents use a searchable multi-select with path hints. If none are
   detected, the prompt offers all known agents and can reuse the last saved
   selection.
3. Ask for project or global scope and explain where each option writes.
4. Ask for symlink or copy only when the selected agents use different target
   directories.
5. Show an installation summary with paths, target agents, file counts, and
   overwrite warnings, then ask `Proceed with installation?`.
6. Show per-skill results and paths. If symlinking fails, report that the files
   were copied instead. End with a warning to review skills because they run
   with the agent's full permissions.
7. Provide flags for scripted use, including repeated `--skill` and `--agent`,
   `--global`, `--yes`, and `--all`.

Vercel's selector is not a numbered parser: its source uses search, arrow-key
navigation, space to toggle, and Enter to confirm. Its prompt also renders a
selected-item summary and can require at least one selection.

### What vpsbuddy borrows and what it does not

The dependency-free Bash prompt borrows the separate selection, summary, and
final-confirmation steps. It adapts the selection to a fixed numbered list and
space- or comma-separated input. It accepts explicit `all` and `none`, rejects
blank input and invalid or mixed tokens, removes duplicates, and prints the
canonical selection before confirmation. It does not add Node.js, npm, a prompt
library, fuzzy search, cursor controls, or saved selection history.

The Vercel project/global and symlink/copy prompts describe a different file
installation problem. vpsbuddy installs selected CLI tools for the chosen admin
user, so it does not need to reproduce those choices for the CLI binaries.
